# 星穹突击队

原创竖版弹幕飞行射击小游戏，参考经典街机飞行射击玩法，不使用《雷霆战机》的商标、角色、UI、音效或图片素材。

## 运行方式

推荐方式：双击 `run.bat` 启动本地服务，然后在浏览器打开：

```text
http://localhost:8088
```

也可以尝试双击 `index.html`。如果浏览器因为本地模块脚本安全策略拦截，请使用 `run.bat`。

## 操作

- 方向键 / WASD：移动
- 鼠标 / 触摸拖动：移动战机
- 自动射击：进入游戏后自动开火
- 空格：使用清屏炸弹
- P：暂停 / 继续
- R：重新开始
- 1 / 2 / 3：调试召唤三类僚机，方便本地试玩时快速看效果

## 已实现内容

- 竖版 Canvas 飞行射击核心循环
- 玩家移动、自动射击、碰撞、生命、分数和最高分
- 使用图像生成制作的统一霓虹科幻精灵图集，已本地化保存到 `assets/`
- 玩家受击判定改为机体中心的小核心点，机翼和外轮廓擦弹不会直接受伤
- 开场三机体选择：
  - 星灵号：诱导光梭，适合新手，追踪稳定
  - 弧月号：广域光羽，扇形覆盖，清小怪舒服
  - 棱光号：聚焦重火，高速高伤，正面输出强
- 玩家子弹是光梭/光束形态，不是圆形；敌方子弹是圆形弹幕，方便观察和躲避
- 三关结构：
  - 第一关：近地轨道，Boss 赤潮巡洋舰
  - 第二关：星尘裂谷，Boss 紫电圣甲
  - 第三关：深空王座，Boss 黑曜母舰
- 击败前两关 Boss 后，战机会加速飞过并保留生命、火力、僚机等配置进入下一关
- 三类敌人：
  - 普通小飞机：速度快、血量低
  - 中型敌机：血量中等、会瞄准射击
  - 精英敌机：血量高、三向弹幕
- Boss：
  - 达到 3200 分或约 70 秒后出现
  - 拥有血条
  - 支持散射、瞄准、多方向环形弹幕
  - 击败后显示胜利结算
- 四类道具：
  - 火力升级
  - 护盾
  - 恢复生命
  - 清屏炸弹
- 三类僚机：
  - 脉冲僚机：提供高速侧翼火力
  - 护卫僚机：拦截靠近玩家核心的敌弹，并提供辅助火力
  - 棱镜僚机：周期发射高伤害激光
- 火力成长：
  - 单发
  - 双发
  - 三向散射
  - 高伤害激光弹
- 难度递增：
  - 随时间和分数提高敌人生成频率、血量和弹幕密度
  - 当前版本已降低早期难度，敌弹更慢，精英敌机更晚、更少出现
- 新增巡航敌人、曲线敌人、炮台敌人和重甲敌人，敌人进入屏幕后会在场内巡航，不再一路飞出屏幕
- 视觉效果：
  - 滚动星空背景
  - 自绘霓虹战机、敌机、Boss、子弹、道具
  - 尾焰、爆炸、命中闪光、道具光圈粒子
- 音效：
  - 射击
  - 爆炸
  - 拾取道具
  - 受伤
  - Boss 出场
